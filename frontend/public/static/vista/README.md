# Спрайты стиля Vista

Всё, что нужно стилю `Vista` (см. `src/ui/vista.css`), лежит здесь.

- `background.png` — обои основной области.
- `logo.png` — логотип форума в выборе форума (извлечён из `vista_logo.svg`, 500×200).
- `icons/` — иконки досок, 32×32 PNG (набор WVista-icons).
- `ui/` — глифы кнопок окна (меню, флажок, «открыть», закрыть) и стрелки; используются как CSS-маски.

## Как назначить иконку доске

Файл `src/ui/vista/boardIcons.ts`: добавьте slug в `BY_SLUG` или регулярку по названию в `BY_TITLE`.
Если ничего не подошло, иконка выбирается по хешу slug из набора `FALLBACK`.
Новые иконки кладите в `icons/` как `<имя>.png`.
